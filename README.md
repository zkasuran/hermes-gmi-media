# GMI media for Hermes

Three standalone backend plugins add GMI Cloud image generation, video generation and speech synthesis to Hermes Agent 0.21.6 or later. Each plugin includes its own shared client. Python 3.11 or later is required.

## Install

Once these plugins are listed in the Hermes catalog:

```sh
hermes plugins install gmi-image
hermes plugins install gmi-video
hermes plugins install gmi-speech
```

The catalog entries are not published yet. The installed Hermes CLI has no `--subdir` install flag. For local development copy the desired plugin directory into `$HERMES_HOME/plugins/` and enable it with `hermes plugins enable gmi-image` (or the corresponding name). Install only the backends you need.

## Setup

Set `GMI_API_KEY` through Hermes setup for the active profile. Get a key at <https://console.gmicloud.ai>. The plugins use Hermes secret scope on every request. They do not read credentials from files themselves.

In Hermes config:

```yaml
image_gen:
  provider: gmi-image
  gmi-image:
    model: seedream-5.0-lite
video_gen:
  provider: gmi-video
  model: Minimax-Hailuo-02
tts:
  provider: gmi-speech
  model: minimax-tts-speech-2.6-turbo
```

Use the Hermes provider picker for live model choices. An explicit model argument overrides the default. For images the provider-scoped model wins over `image_gen.model`. A shared image model from another provider is ignored. An explicit or scoped new GMI model is fetched even when absent from the cached list. Video defaults differ for text and image inputs. Speech excludes music models.

## Cost and data disclosure

Every generation call spends the user's GMI credits with no Hermes approval prompt. Video is often charged per second. Prices come live from GMI and are shown as supplied, not computed into a total. GMI billing units can be inconsistent.

Prompts and image URLs go to console.gmicloud.ai. Results are fetched from URLs GMI returns. There is no telemetry. Plugins read no user media files outside the `$HERMES_HOME` cache. Hermes itself reads its config and active profile. There are no background processes. Catalog refresh uses bounded in-process threads. Audio is written to the output path supplied by Hermes.

## Limits

- Image inputs must be public HTTP or HTTPS URLs. Local files are rejected.
- Video reference images are ignored and reported in `dropped`.
- Speech has no streaming support. Unsupported output formats fall back to an offered format with the matching file extension.
- GMI model parameters differ. Unsupported requested options are dropped and reported. Numeric options use the closest valid value.
- Image sizes above 4,194,304 pixels are not selected when safe choices exist. If all explicit size choices exceed that cap the model default remains in effect. This is not an output size guarantee.
- Catalog reads wait at most 4.5 seconds then use cached data or fallbacks. Availability only checks whether a key exists.
- Some GMI models fail on GMI's side with the parameters their schema declares. In the live checks `Kling-Text2Video-V1.6-Standard` answered that `model_name` is required, which its schema does not list. `gemini-2.5-flash-image` returned upstream errors on image edits. The defaults are models that worked in the live checks. Pass `model` to use another.
- Paid submissions are never retried automatically. After a timeout check the GMI console before submitting again.

## Development

Use the Hermes venv with pytest and httpx installed:

```sh
export HERMES_HOME=/tmp/hh
export PYTHONDONTWRITEBYTECODE=1
python scripts/sync_shared.py
python scripts/sync_shared.py --check
python -m pytest -q
hermes plugins validate gmi-image
hermes plugins validate gmi-video
hermes plugins validate gmi-speech
```

Edit `shared/gmi_media.py` then sync its three copies. Tests use captured schemas and a loopback server. An autouse socket guard blocks external connections. Image saves are mocked and no images are generated by tests.

Only a human should run `python scripts/live_check.py image --max-usd 3`. Other modes are `image-edit`, `speech`, `video`, `video-image` and `all`. Image input modes need `--image-url URL`. Select a model with `--model ID`. Unknown billing units require `--i-accept-unknown-cost`. That flag accepts costs that cannot be capped by an estimate. Outputs go to git-ignored `live-output/`. Never preview an image above 1990 pixels on its longest edge.

The code was written with an AI coding assistant (gpt-6-astra via Codex), then reviewed, changed and verified by the maintainer.

Live checks on 9 November 2026 against the real GMI API, using `scripts/live_check.py`: image generation with `seedream-5.0-lite`, image edit with `luma-uni-1.1`, speech with `minimax-tts-speech-2.6-turbo` (a valid MP3 of 2.8 seconds), text to video with `Minimax-Hailuo-02` (5.9 seconds) and image to video with `Minimax-Hailuo-2.3-Fast` (5.9 seconds). Not working in those checks: `Kling-Text2Video-V1.6-Standard` (see Limits) and `gemini-2.5-flash-image` for edits (upstream errors from GMI). Each plugin was exercised in Hermes through its provider class and the Hermes helper functions, not through a full agent session.
